---
title: 'Plot'
description: 'Pick a story structure, let the AI plan the chapters or pages, shape the tension curve and rewrite the plan from any point with what-if.'
---

Plot is the plan of the book, from the first chapter to the last. The plan is a list of chapters, or pages for a picture book, each with a summary and a beat.

## Choose a structure

Pick a story structure from the list. Each structure has its own beats, and the AI uses them when it plans the book.

Set how many **Chapters** (or **Pages** for a picture book) the book needs. Add anything the plan must include in **Anything the plan must include? (optional)**, such as "the mother comes back in the last chapter".

## Plan the book

Press **Plan the book**. Plot shows **Working on the plan…** while the AI works, then fills in the chapters.

- If nothing is written yet, **Plan it again** replaces the plan.
- If the manuscript already has text, Plot asks **Replace the current plan?** before it replaces anything. **Undo** puts the previous plan back.

## Shape the tension curve

The **Tension curve** shows one point for each chapter. Drag a point up or down to set how tense that chapter is. The plan does not need to be exact. The curve helps you see where the book sags or spikes.

## Edit a chapter

Each chapter has:

- **Title**
- **What happens here?**, a short summary.
- **Beat**, the structure step the chapter fills. **No beat** leaves it free.
- **Point of view**, such as first person or a particular character.

Use **Move up** and **Move down** to reorder chapters, **Remove** to delete one, and **Add a chapter** to add one at the end. Picture books use **Add a page**.

## What if…

**What if…** on a chapter asks a question, such as "what if the lighthouse burns down here?". Plot rewrites the plan from that chapter on, and keeps the chapters before it. Use **Undo** if the new plan is worse.

When a chapter's plan changes after its scene was written, the scene shows **The plan changed after this was written.** Rewrite the scene or keep it.
