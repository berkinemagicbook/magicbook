The media library keeps the images you upload, so you can reuse them in your books. Open it from **Library → Media** in the sidebar.

MagicBook accepts images only. Video uploads are off unless the site owner turns them on.

## Upload images

- Drop images anywhere on the page, or press **Browse files**.
- Choose **Upload to folder** to file the new images in a folder. Leave it blank to keep them loose.
- Each upload shows its progress as **Waiting**, **Uploading**, **Uploaded** or **Failed**. **Cancel** stops an upload, and **Retry** starts a failed one again. **Clear finished** removes the finished rows.

The size limit for each image is set by the site owner. If an image is too large, the upload fails. The limit is set on [General settings](/admin/general-settings).

## Find and sort files

- **Search files** looks in names.
- **All folders** filters by folder.
- **Images** filters the list to images.
- Sort by **Newest**, **Oldest**, **Name** or **Largest**.
- Switch between **Grid** and **List** views.

## Work with a file

Select a file to see its preview. The file menu offers:

| Action | What it does |
|---|---|
| **Copy link** | Copies the file's address. |
| **Download** | Downloads the original file. |
| **Rename** | Changes the file name. |
| **Move to folder** | Moves the file into a folder. Leave the folder name blank to move it out of any folder. |
| **Delete** | Deletes the file after you confirm. This cannot be undone. |

**Alt text** describes what the image shows for people who cannot see it. Write it in the file's details and press **Save alt text**.

## Storage

The **Media storage** meter shows how much of your plan's space you use. It shows **Unlimited** when your plan has no limit, and **Almost full** when you are close to it. See [Plans](/saas/plans).
