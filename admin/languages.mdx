title: 'Languages'
description: 'Choose the site languages, translate the interface strings, and publish the translations for customers.'
---

**Backend Settings → Language Manager** holds the translations of the interface. MagicBook ships in 14 languages: Arabic, Danish, German, Greek, English, Spanish, French, Indonesian, Italian, Kazakh, Dutch, Portuguese (Brazil), Swedish and Thai.

## Choose the languages customers see

Only the languages you enable appear in the language menu in each customer's account menu. A customer who picks a language sees the whole site in it, and the choice is remembered.

## Set the default language

Choose the default language on the Language Manager home page. Visitors who have not picked one see the site in this language.

## Translate

- Open a language to see its strings, with the English text beside each one.
- Use **Search** to find a string.
- Enter the translation in the box for each string and save it.
- **New string** adds a string that the site does not have yet. **New language** adds a language that is not in the list.

## Publish translations

**Publish all** writes every language to the site. If the site shows a string in English after you publish, use **Regenerate** to rebuild the language files.

<Note>
The Language Manager translates the interface only. Books keep the language they were written in.
</Note>
