**Frontend Settings** holds everything customers see on the public site before they sign in.

## Frontend Settings

- **Frontend Page**: when turned off, the main landing page is not available to anyone.
- **Custom Landing Page URL**: turn on **Enable** and paste a link to use another page as the landing page.
- **Social Media Information**: the links to your Twitter, Facebook, LinkedIn, Instagram, YouTube and TikTok pages.

## SEO Manager

Set the title, description, keywords, author and canonical URL for the **home page**, the **login page** and the **registration page**. Search engines and social previews use these values.

## Logos

Upload the logos used across the site:

- **Frontend Logo** and **Frontend Collapsed Logo**, for the public site.
- **Favicon**, the small icon in the browser tab.
- **Dashboard Light Logo**, **Dashboard Dark Logo**, **Dashboard Collapsed Light Logo** and **Dashboard Collapsed Dark Logo**, for the app's sidebar in each mode.

## Pages

Edit the **Privacy Policy** and **Terms of Service** text. The content accepts HTML, such as `<h2>`, `<p>`, `<ul>`, `<li>` and `<a>`. The **Live preview** shows the result. Press **Save Privacy Policy** or **Save Terms of Service**.

## FAQs Manager

The questions on the landing page. Each FAQ has a **Question**, an **Answer** and a **Status**. Only **Active** FAQs are shown. Use **Search questions...** to find one.

## Testimonials

Quotes from customers shown on the landing page. Each one has a **Customer** name, **Role**, **Company**, a **Rating** out of five, an optional avatar and a **Status**. Mark a testimonial **Featured** to show it in the highlighted style. Only **Active** testimonials are shown.

## Google Adsense

Turn on **Enable Google AdSense** to load the ad code on public pages. Enter your **Publisher ID**, choose whether **Auto Ads** runs, and add the **Ad unit slot ID** for each placement. Turning the master switch off removes all ad code from the public site.

Blog posts are managed on the [Blog](/admin/blog) page.
