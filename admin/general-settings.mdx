**Platform → General Settings** has two tabs: **General** and **Plugins**.

## General tab

- **Default Registration Credits**: the credits a new account receives when it registers for the first time. Set it to zero if new accounts should start with nothing.
- **Default Storage**: where new uploads are stored. **Local server** keeps files on the same machine as MagicBook. Cloud storage appears here once a storage plugin is installed and enabled. See [Storage](/advanced/storage).
- **Upload limits**: the largest **Images (MB)** a customer may upload. The **Videos (MB)** field appears only when video uploads are turned on.
- **Free tier**: a link to **Finance → Free tier**, when the SaaS plugin is installed. Free tier limits are set there, not on this page.

Press **Save** to keep the changes.

## Plugins tab

The Plugins tab holds one card for each installed plugin. Open a card to change its settings:

- **Audiobook Studio**. See [Audiobook Studio](/plugins/audiobook-studio).
- **Voice Cloning**. See [Voice Cloning](/plugins/voice-cloning).
- **SaaS Business**. See [SaaS plugin](/plugins/saas).
- Cloud storage plugins, such as **Amazon S3**, **Wasabi**, **Cloudflare R2** and **Google Cloud Storage**. Each one adds a card here after you install it.

When no plugin is installed, the tab says **No plugins installed yet.** Install plugins from [Plugins and themes](/admin/plugins-and-themes).
