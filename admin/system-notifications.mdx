---
title: 'System notifications'
description: 'Review and manage the notifications that MagicBook sends to the admin account.'
---

**Notifications → System Notification** lists the system notifications on the admin account.

## Manage notifications

- **Mark read** marks one notification as read. **View** opens it.
- **Mark all as read** marks every notification as read.
- **Delete** removes a notification after you confirm.

When there are no notifications, the page says **No notifications yet.**

The admin dashboard shows the number of unread notifications. See [Admin dashboard](/admin/dashboard).

Customers have their own inbox. See [Notifications](/account/notifications).
