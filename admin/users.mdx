The **Accounts** section holds every customer account.

## Accounts dashboard

**Accounts → Dashboard** shows an overview: total registered users, users online now, visitors today, the countries your users come from, and new registered users per month. The countries map uses Google Maps. Without a Maps key it shows **Google Maps is Disabled**. See [Google Maps](/advanced/google-maps).

## Users

**Accounts → Users** lists every account with the total count. Select a user to view the account.

### Create a user

Press **Create User** and fill in:

- **Login credentials**: email address and password, confirmed twice.
- **Personal information**: full name, company, phone, website and address.
- **Account settings**: the group (**User** or **Subscriber**), the status (**Active**, **Inactive**, **Suspended** or **Pending**) and the **Credits** the account starts with.

### View a user

The user page shows:

- **Profile details**: user ID, referral ID, joined date, last seen, whether two-factor authentication is **Enabled**, and the email opt-in.
- **Subscription**: the plan, its status and when it renews. **No active subscription** shows when none.
- **Recent orders**, with a link to all orders.
- **Credit history**: every credit movement. A hold can be released when its work will not be charged, with **Release this hold?**.
- **Support tickets** from that user.

### Edit a user

**Edit Profile** changes the same details as the create form. Use it to change the status, for example to suspend an account.

### Delete a user

The **Danger Zone** at the bottom deletes the account. Deleting cannot be undone. Set the account to **Inactive** or **Suspended** if you only need to block it.

## Activity monitoring

**Accounts → Activity Monitoring** shows the real-time activity of users: who is online and what they are doing.
