**AI → Image Models** chooses the models that draw. There are three jobs, and each can use one model or **Automatic**.

## The jobs

| Job | Used for |
|---|---|
| **Character sheet** | A reference picture of each character. Every later picture of that character is drawn from it. |
| **Page** | The picture for each page of a picture book. |
| **Cover** | The cover of a picture book. |

**Who draws what** shows which model draws each job. A job shows **No model can draw these yet** until you enable a model with a saved key.

## Reference images

Only models marked as taking **References** can use a character sheet. A model without references shows **This model cannot use character sheets**, and its pictures may not match the same character from page to page. Choose one that accepts references for the **Character sheet** job, and use it for **Page** too if you want the characters to match.

## Enable and price a model

Each model row shows its provider, its tier (**Standard** or **Premium**), whether it has a key (**No key** when not), its **References** support and its **Credits** per picture.

- Switch the model on to make it available.
- Set the credits per picture. A picture costs this amount whatever the size.
- Choose **Save** to keep the changes, or **Save defaults** to save the job choices.

Premium models can be limited to plans that include **Premium illustration models**. See [Plans](/saas/plans).

## Art styles

Art styles add the look to every picture. They are set on the **Books → Art styles** page. See [Art styles](/admin/art-styles).

## Costs

Each picture costs the credits set for its model. The credits are held when the picture starts, charged when it is drawn, and released if the drawing fails. See [AI tools](/user-guide/ai-tools).
