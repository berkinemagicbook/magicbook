---
title: 'Admin panel overview'
description: 'Map of the admin sidebar: what each section does and which pages appear only when a plugin is installed.'
---

The admin panel is the sidebar you see when you sign in with an admin account. This page lists every section in the order it appears. Pages from the SaaS plugin appear only after you install it.

## Dashboard

- **Dashboard** is the first screen. See [Admin dashboard](/admin/dashboard).

## Finance (SaaS plugin)

- **Finance Dashboard**, **Pricing Plans**, **Free tier**, **Orders**, **Subscriptions**, **Invoice Settings**, **Payment Gateways** and **Finance Settings**. See [SaaS plugin](/plugins/saas).

## Affiliates (SaaS plugin)

- **Accounts**, **Earnings** and **Payouts** for the referral program. See [Referrals](/saas/affiliates).

## Books

- **Book settings** sets the longest books each format can be. See [Book settings](/admin/book-settings).
- **Art styles** holds the picture styles customers choose from. See [Art styles](/admin/art-styles).

## AI

- **AI Providers** saves the keys. See [AI providers](/admin/ai-providers).
- **Text Models** and **Image Models** choose the models and their credit costs. See [Text models](/admin/text-models) and [Image models](/admin/image-models).
- **Voices** sets the narrators and voice input. See [Voices](/admin/voices).
- **Generation activity** lists every AI step. See [Generation activity](/admin/generation-activity).
- **Safety** sets the thresholds, and the **Moderation log** lists what was blocked. See [Safety](/admin/safety).

## Accounts

- **Dashboard**, **Users** and **Activity Monitoring**. See [Users](/admin/users).

## Support

- **Tickets** lists customer tickets. See [Support tickets](/admin/support-tickets).

## Notifications

- **System Notification** manages notices for customers. See [System notifications](/admin/system-notifications).

## Platform

- **Plugins** and **Themes**. See [Plugins and themes](/admin/plugins-and-themes).
- **General Settings**: default credits, storage and plugin cards. See [General settings](/admin/general-settings).
- **Backend Settings**: **Global Settings**, **Auth Settings**, **Registration Settings**, **SMTP Settings**, **GDPR Settings** and **Language Manager**. See [Global settings](/admin/global-settings), [Registration and login](/admin/registration-and-login), [SMTP](/admin/smtp), [Privacy and GDPR](/admin/privacy-gdpr) and [Languages](/admin/languages).
- **Frontend Settings**: landing page, **SEO Manager**, **Logos**, **Pages**, **FAQs Manager**, **Testimonials**, **Blogs Manager** and **Google Adsense**. See [Website content](/admin/website-content) and [Blog](/admin/blog).
- **System Status**: whether everything MagicBook needs is ready. See [System status](/admin/system-status).
- **Activation** and **Update**. See [License activation](/license/activation) and [Update instructions](/updates/update-instructions).

<Note>
Admin accounts are never limited by plans or credits. Test features with an admin account, and use a customer account to check what customers see.
</Note>
