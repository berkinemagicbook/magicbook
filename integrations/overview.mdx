MagicBook connects to outside services with the keys you save in the admin panel. Each service is called directly. There is no gateway or router between MagicBook and the provider.

## AI providers

| Provider | Used for | Page |
|---|---|---|
| OpenAI | Writing, pictures and the free safety check | [OpenAI](/integrations/ai/openai) |
| Anthropic | Writing | [Anthropic](/integrations/ai/anthropic) |
| Google Gemini | Writing and pictures | [Google Gemini](/integrations/ai/gemini) |
| xAI Grok | Writing | [xAI Grok](/integrations/ai/xai) |
| Black Forest Labs (FLUX) | Pictures | [FLUX](/integrations/ai/flux) |
| Ideogram | Pictures | [Ideogram](/integrations/ai/ideogram) |
| Recraft | Pictures | [Recraft](/integrations/ai/recraft) |
| ElevenLabs | Narration and voice input | [ElevenLabs](/integrations/ai/elevenlabs) |

Save the keys on [AI providers](/admin/ai-providers).

## Social login

Customers can sign in with Google, Facebook, X (Twitter) or LinkedIn. Each provider needs an app that you create on the provider's developer site, and its keys saved on [Registration and login](/admin/registration-and-login).

- [Google](/integrations/login/google)
- [Facebook](/integrations/login/facebook)
- [X (Twitter)](/integrations/login/x)
- [LinkedIn](/integrations/login/linkedin)
